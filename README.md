# English File Elementary – Visor

Visor de páginas del libro *English File Elementary (5th edition, Multipack B)* para uso personal.

Abrir: https://vbeldad.github.io/english-book/

## Añadir páginas
1. Sube la foto (recortada y enderezada) a la carpeta `pages/`.
2. Añade una línea a la lista `PAGES` en `index.html`, p. ej. `{ file: 'sb-60.jpg', label: 'Student Book p. 60' },`

Atajos: ← → para pasar página, + / − / 0 para el zoom.
